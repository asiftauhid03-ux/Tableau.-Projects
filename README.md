# Tableau.-Projects
I created multiple Tableau dashboards to analyze sales performance across categories, sub-categories, and regions. The first dashboard shows overall sales using a pie chart and bar charts, making it easy to compare product performance. I also built a line chart dashboard to track monthly sales trends over several years for different product categories. Finally, I designed a map visualization that displays sales by state, helping users understand regional sales patterns at a glance. These dashboards show my ability to create clear, interactive visuals that help businesses understand their data quickly.
